# FlyRank — Assignment 3 (Demo React App)

This is a small example React app built with Vite as part of the assignment. It demonstrates a searchable list of sample flights with sorting.

Quick start:

```bash
npm install
npm run dev
```

Open http://localhost:5173 after running `npm run dev`.
