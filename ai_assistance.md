# How AI assisted during implementation

- Initial scaffolding: AI produced the Vite config, `package.json`, and a working `index.html` + `main.jsx` entry.
- Feature design: AI suggested component structure (`App`, `FlightCard`) and provided sample flight data to iterate UI logic quickly.
- Implementation: AI generated the React components, search and sorting logic, and basic CSS to make the UI presentable.
- Documentation: AI drafted `README.md` and `prompts.md`.

AI sped up the initial implementation; afterwards code was reviewed and small manual improvements were applied (see `manual_changes.md`).
